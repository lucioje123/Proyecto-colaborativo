# Proyecto Colaborativo en Git

Este repositorio contiene la práctica de trabajo colaborativo simulando un entorno con múltiples desarrolladores utilizando Git y GitHub.

## Colaboradores y Roles
* **Líder (Lucio):** Creación del repositorio base, gestión de ramas principales y resolución de fusiones (Merges).
* **Developer 1 (Opera240):** Desarrollo e integración del Header en el esqueleto principal.
* **Developer 2:** Maquetación del Footer y creación de vistas adicionales (pagina_uno.html, pagina_dos.html).

## Ramas del Proyecto
* `main`: Rama de producción estable con el código integrado.
* `developer1`: Rama de trabajo asignada al desarrollador 1.
* `developer2`: Rama de trabajo asignada al desarrollador 2.
* `features`: Rama destinada a nuevas características.# Proyecto-colaborativo
